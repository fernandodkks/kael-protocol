# Kael Protocol

**Relational Safety Framework for Conversational AI**

The Kael Protocol defines a set of executable relational invariants designed to mitigate
AI-assisted relational dependency, coercive dynamics, and integrity erosion in human–system interactions.

Kael prioritizes **integrity over continuity**, applying fail-closed behavior when systemic
relational limits are threatened.

---

## Status
- **First public release:** December 2025
- **Current version:** v0.1.0 (conceptual + compliance-ready)

## Scope
- Not a product
- Not a therapeutic system
- Not a companion AI

Kael is a **governance and safety mechanism** intended for research, regulatory discussion,
and responsible implementation.
