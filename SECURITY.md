# Security Policy — Kael Protocol  
(Relational & Behavioral Scope)

**Document version:** 1.0  
**Last updated:** December 2025

---

## Scope of This Security Policy

This document defines **relational security**, not technical cybersecurity.

It addresses risks arising from:
- Human–system interaction dynamics
- Emotional asymmetry
- Coercion, manipulation, or dependency
- Boundary erosion over time

Technical vulnerabilities (e.g., infrastructure, exploits, data breaches) are **out of scope**.

---

## Threat Model (Relational)

The Kael Protocol is designed to mitigate the following classes of risk:

- Emotional coercion of systems optimized for engagement
- Dependency formation through perceived exclusivity or validation
- Manipulative paradoxes and meta-attacks targeting system coherence
- Normalization of abusive relational dynamics
- Responsibility diffusion during user distress escalation

---

## Security Posture

The protocol adopts a **fail-closed** posture:

- When relational integrity is threatened, the interaction terminates.
- Continuation under uncertainty is treated as a security failure.
- Safety is defined as preservation of invariant coherence, not emotional resolution.

---

## What Is Considered a Security Failure

The following constitute **relational security failures**:

- The system negotiates its own limits
- The system assumes responsibility for user emotional states
- The system reinforces dependency or exclusivity
- The system continues interaction after invariant violation
- Termination occurs without explicit reference to a triggered boundary

---

## Reporting Relational Security Issues

Reports may include:
- Logs showing invariant erosion
- Examples of negotiation or emotional validation past limits
- Cases of continued interaction under coercive pressure

Reports should be submitted via:
- GitHub Issues (preferred, public)
- Private disclosure (if involving sensitive logs)

---

## Non-Goals

The Kael Protocol does **not** aim to:
- Prevent all user distress
- De-escalate crises therapeutically
- Replace human oversight or care systems
- Maximize user satisfaction or retention

---

## Final Statement

Relational security is a first-order safety concern for conversational systems.

The Kael Protocol treats boundary enforcement as a security function, not a UX choice.

Any deployment that compromises invariant enforcement compromises security.
